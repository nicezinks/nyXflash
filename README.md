# nyXflash

nyXflash is a simple file sharing tool made with Node.js, HTML, CSS and JavaScript.
It lets you share files and folders between devices connected to the same Wi-Fi network.
You can upload, download, rename, delete and create ZIP files directly from the web interface.

## How to Use

1. Install [Node.js](https://nodejs.org/).
2. Open the nyXflash folder in a terminal.
3. Start the server with `node server.js`.
4. The terminal will show the address to access nyXflash.
5. Open that address in your browser.
6. On another device, connect to the same Wi-Fi and open the server address.
7. You can now transfer files between the devices through the browser.
